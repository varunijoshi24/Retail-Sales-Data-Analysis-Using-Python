# Job Title Classification — NLP / Machine Learning

## Overview
This project focuses on classifying job titles into categories using Natural Language Processing (NLP) and Machine Learning techniques.

## Objectives
- Load and inspect job title data.
- Clean and preprocess textual data.
- Convert text into numerical features.
- Apply NLP techniques for text processing.
- Train a machine learning classification model.
- Evaluate model performance using appropriate metrics.
- Predict job categories based on job titles.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)

## Project Workflow
1. Data loading and inspection
2. Text cleaning and preprocessing
3. Text feature extraction
4. Model training
5. Model evaluation
6. Job title category prediction

## Key Learnings
- Text preprocessing
- Natural Language Processing
- Feature extraction
- Machine learning classification
- Model evaluation
